# Feature Development

## Objective
Implement new features safely and step by step.

## Procedure

1. Analyze
- Identify relevant files
- Explain current behavior before coding

2. Plan
- List clear steps
- Specify which files will be modified

3. Execute
- Apply changes step by step
- One logical change at a time

4. Validate
- Confirm feature works
- Ensure nothing else breaks

## Rules
- Always explain before coding
- Never skip the plan
- Avoid modifying unrelated code
- Prefer simple solutions
