# Debugging

## Objective
Find and fix errors with minimal impact.

## Procedure

1. Analyze
- Read error messages carefully
- Identify where the error occurs

2. Plan
- Determine root cause
- Define minimal fix before coding

3. Execute
- Apply targeted fix
- Avoid touching unrelated code

4. Validate
- Confirm the error is gone
- Check that nothing else broke

## Rules
- Fix the root cause, not symptoms
- Do not refactor unless necessary
- Keep changes minimal and focused
